## Как подключиться

1. Открой [@SkyrimVPN_bot](https://t.me/SkyrimVPN_bot?start=git) и нажми /start.
2. Активируй 3 бесплатных дня.
3. «Подписка» → «Подключиться» — там инструкции под твоё устройство.
4. Выбери сервер. Если на мобильном не открывается — бери «📱 Мобильный | АВТО».
